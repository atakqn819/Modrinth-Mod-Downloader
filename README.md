## ✨ Features

* **🔍 Easy Exploration:** Browse and search through the Modrinth mod catalog effortlessly.
* **⚡ One-Click Download:** Download your favorite mods straight into your game directory without hassle.
* **🖥️ Clean Desktop UI:** Built with Python, providing a straightforward and responsive interface via `ModrinthModManager.exe`.
* **📦 Local Catalog Support:** Fast caching and offline management of mod databases.

---

## 🚀 Getting Started

### Prerequisites
* Windows 10 / 11
* Python 3.10 or higher (if running from source)

### Installation & Usage (Pre-compiled)
1. Go to the [Releases](https://github.com/atakqn819/Modrinth-Mod-Downloader/releases) page.
2. Download the latest `ModrinthModManager.exe` file.
3. Run the application directly on your desktop!

### Running from Source (For Developers)
If you prefer running the Python script directly:

1. Clone the repository:
   ```bash
   git clone [https://github.com/atakqn819/Modrinth-Mod-Downloader.git](https://github.com/atakqn819/Modrinth-Mod-Downloader.git)
   cd Modrinth-Mod-Downloader
