# Modrinth Mod Downloader

A lightweight and fast GUI/CLI tool designed to search, filter, and download Minecraft mods directly from Modrinth.

## ✨ Features

- **Fast Search & Filter:** Quickly search mods by categories, game versions, and mod loaders (Forge, Fabric, Quilt).
- **Automated Downloads:** Download mods and their dependencies with a single click.
- **Clean & Intuitive UI:** Simple and user-friendly interface built with Python.

## 🚀 Installation & Usage

### Download Pre-compiled Executable
1. Go to the [Releases](https://github.com/atakqn819/Modrinth-Mod-Downloader/releases) page.
2. Download the latest `ModrinthModManager.exe` file.
3. Run the executable to start managing your mods.
